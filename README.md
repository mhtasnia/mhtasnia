## 🔬 Research:
**🥔 MtuberAgent: An Explainable Multi-Agent Framework for Export-Quality Potato Grading Based on Surface Defects** `Ongoing`<br>
A two-stage segmentation cascade that isolates individual tubers and segments four surface defect classes — scab, rot, greening, and mechanical damage. A four-agent pipeline grades each potato and batch against **UNECE Standard FFV-52**, produces a visual justification for every detection, and compiles a queryable inspection report. Deployed as a browser-based application.<br>
`PyTorch` `Ultralytics YOLO` `OpenCV` `Python` — *Manuscript in preparation*

<br>

**👁️ MSRA-Net: An Efficient Deep Learning Architecture with Spatial Attention** `Presented at EICT 2025`<br>
A deep learning architecture for **Diabetic Retinopathy Classification** from retinal images, designed around spatial attention mechanisms to improve classification accuracy on medical imaging datasets.<br>
`TensorFlow` `Keras` `Python`
